소개

견적서나 거래명세서를 빠르게 만들어 인쇄하거나 PDF로 보내야 할 때 쓰는 간단한 도구입니다. 엑셀이나 한글 양식을 내려받지 않고 브라우저에서 바로 입력할 수 있습니다.

할 수 있는 일

  • 견적서·거래명세서 중 문서 종류 고르기
  • 공급자·공급받는자 정보와 품목(품명, 규격, 수량, 단가) 입력, 품목 추가·삭제
  • 공급가액·부가세(별도/포함/면세)·합계와 한글 금액 자동 계산
  • A4 인쇄, 브라우저 인쇄 기능을 이용한 PDF 저장
  • 입력 내용을 .json 파일로 내려받아 두었다가 다시 불러오기

하지 않는 일

  • 입력 내용을 서버로 보내거나 저장하지 않습니다. 모든 처리는 브라우저 안에서 이루어집니다. 자세한 내용은 개인정보 처리 안내를 보세요.
  • 세금계산서를 발급하지 않습니다. 이 도구로 만든 문서는 세금계산서가 아닙니다.
  • 문서의 법적 효력이나 세무 신고 인정을 보장하지 않습니다.
  • 사업자등록번호는 숫자 10자리 형식만 확인하며, 실제 등록 여부나 상태는 확인하지 않습니다.
  • 면세 해당 여부 등 세무 판단을 하지 않습니다.

계산에 대해

금액은 원 단위 정수로 계산하고, 반올림 규칙을 도구 화면과 작성 가이드에 적어 두었습니다. 거래처나 회계 프로그램의 규칙과 다를 수 있으니 보내기 전에 금액을 직접 확인하세요.
