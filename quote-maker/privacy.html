개인정보 처리 안내

시행일: 2026년 10월 5일

1. 입력 내용은 서버로 전송되지 않습니다

이 사이트의 견적서·거래명세서 만들기 도구에 입력한 내용(사업자등록번호, 상호, 대표자, 주소, 연락처, 품목, 금액, 비고 등)은 사용자의 브라우저 안에서만 계산·표시됩니다. 입력 내용은 운영자 서버나 제3자에게 전송·저장되지 않습니다.

  • 도구 페이지에는 콘텐츠 보안 정책(connect-src 'none')을 적용해, 페이지의 스크립트가 외부로 데이터를 보내는 요청(fetch, XHR, beacon, WebSocket 등)을 브라우저가 차단하도록 했습니다.
  • 외부 스크립트, 외부 글꼴, 외부 이미지를 불러오지 않습니다.
  • 입력 내용을 브라우저 저장소(로컬 저장소, 세션 저장소 등)에도 저장하지 않습니다. 페이지를 닫거나 새로고침하면 입력 내용은 사라집니다.
  • '입력 내용 파일로 내려받기'를 누르면 입력 내용이 .json 파일로 사용자 기기에 저장됩니다. 이 파일에는 입력한 사업자등록번호·상호·대표자·주소·연락처 등 공급자와 공급받는자 정보가 그대로(암호화 없이 읽을 수 있는 텍스트로) 들어 있으므로 다른 사람과 공유하거나 공용 기기에 두지 않도록 주의하세요. 이 파일과 인쇄·PDF로 저장한 문서는 사용자 기기에 그대로 남으므로 직접 관리해야 합니다. '파일 불러오기'로 고른 파일도 브라우저 안에서만 읽습니다.

2. 쿠키와 추적

이 사이트는 쿠키, 로컬 저장소, 방문 분석 도구, 광고 추적 코드를 사용하지 않습니다.

다만 사이트 파일을 전달하는 호스팅 서비스는 일반적인 웹 서버처럼 접속 기록(IP 주소, 요청 시각, 브라우저 정보 등)을 남길 수 있습니다. 이 사이트는 GitHub Pages(GitHub, Inc.)에서 제공되며, 해당 접속 기록은 GitHub의 정책에 따라 처리될 수 있습니다. 운영자는 별도로 접속 기록을 수집하지 않습니다.

3. 수집하는 개인정보

운영자가 직접 수집하는 개인정보는 없습니다. 문의를 보내시는 경우에 한해, 답변을 위해 보내신 이메일 주소와 내용을 확인하며, 이는 문의에 답변하는 목적으로만 이용하고 문의 처리가 끝나면 지체 없이 삭제합니다.
