개인정보 처리 안내

시행일: 2026년 10월 5일

1. 사진은 서버로 전송되지 않습니다

이 사이트의 사진 규격 맞추기 도구는 사용자가 고른 사진을 사용자의 브라우저 안에서만 읽고, 자르고, 압축합니다. 사진 파일과 변환 결과는 운영자 서버나 제3자에게 전송·저장되지 않습니다.

  • 사진은 브라우저의 Canvas 기능으로 처리되며, 결과는 브라우저 메모리 안의 임시 주소(blob)로만 만들어져 다운로드됩니다.
  • 도구 페이지에는 콘텐츠 보안 정책(connect-src 'none')을 적용해, 페이지의 스크립트가 외부로 데이터를 보내는 요청(fetch, XHR, beacon, WebSocket 등)을 브라우저가 차단하도록 했습니다.
  • 외부 스크립트, 외부 글꼴, 외부 이미지를 불러오지 않습니다.
  • 페이지를 닫거나 새로고침하면 불러온 사진과 결과는 브라우저에서 사라집니다. 다만 사용자가 '다운로드'한 파일은 사용자 기기에 그대로 저장되므로 직접 관리해야 합니다.

2. 쿠키와 추적

이 사이트는 쿠키, 로컬 저장소, 방문 분석 도구, 광고 추적 코드를 사용하지 않습니다.

다만 사이트 파일을 전달하는 호스팅 서비스는 일반적인 웹 서버처럼 접속 기록(IP 주소, 요청 시각, 브라우저 정보 등)을 남길 수 있습니다. 이 사이트는 GitHub Pages(GitHub, Inc.)에서 제공되며, 해당 접속 기록은 GitHub의 정책에 따라 처리될 수 있습니다. 운영자는 별도로 접속 기록을 수집하지 않습니다.

3. 수집하는 개인정보

운영자가 직접 수집하는 개인정보는 없습니다. 문의를 보내시는 경우에 한해, 답변을 위해 보내신 이메일 주소와 내용을 확인하며, 이는 문의에 답변하는 목적으로만 이용하고 문의 처리가 끝나면 지체 없이 삭제합니다.

4. 앞으로 바뀔 수 있는 점
